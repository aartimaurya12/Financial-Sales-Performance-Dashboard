# Financial-Sales-Dashboard

# Project Overview
This project focuses on analyzing sales performance using Power BI to identify key business insights and performance gaps.

The dashboard provides a comprehensive view of sales metrics such as total sales, target achievement, and variance analysis. It helps businesses understand performance trends and identify areas for improvement.

# Objectives
- Analyze overall sales performance
- Compare actual vs target sales
- Identify underperforming and top-performing sales representatives
- Highlight revenue gaps and improvement areas

# Key Insights
- Total Actual Sales reached $19M against a target of $19M
- Only 2 out of 14 monthly targets were achieved
- Overall variance stood at -$367K with a variance percentage of 1.9%
- Identified top underperforming and top-performing sales representatives
- Highlighted revenue loss areas

# Tools & Technologies
- Power BI  
- DAX  
- Data Modeling  
- KPI Analysis  
- Data Visualization
